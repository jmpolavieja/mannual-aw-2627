# 🧪 Práctica Guiada de Aula: Despliegue de un Aula Virtual en Moodle
::: info

:::
## Objetivos:
Configurar las extensiones de PHP requeridas en XAMPP, instalar Moodle localmente, estructurar la jerarquía de categorías/cursos, crear usuarios y exportar una copia de seguridad en .mbz.
## Pasos a realizar:
* Pre-instalación en XAMPP:
  * Modifica `C:\xampp\php\php.ini` para activar `extension=intl` y establecer `max_input_vars = 5000`.
  * Reinicia el servicio Apache desde el panel de control de XAMPP.
  * Crea la base de datos `bd_moodle` con cotejo `utf8mb4_unicode_ci` en phpMyAdmin.
  * Crea manualmente la carpeta `C:\xampp\moodledata`.
* Instalación Web de Moodle:
  * Descarga el paquete de Moodle y descompresiónalo en `C:\xampp\htdocs\moodle`.
  * Ejecuta el asistente web desde `http://localhost/moodle` y completa la instalación indicando la ruta `C:\xampp\moodledata`.
* Estructuración Académica y Alta de Cursos:
  * Accede a `Administración del sitio > Cursos > Gestionar cursos y categorías`.
  * Crea la categoría: `Formación Profesional > Informática > 2º SMR`.
  * Crea el curso: `Aplicaciones Web - Altair` (Nombre corto: `AW-2627`).
* Gestión de Usuarios y Matriculación:
  * Crea dos cuentas de usuario desde `Administración del sitio > Usuarios > Añadir usuario`:
    * `profe_altair` (Rol asignado en el curso: **Profesor**).
    * `alumno_altair` (Rol asignado en el curso: **Estudiante**).
* Diseño de Sección y Copia de Seguridad:
  * Dentro del curso `AW-2627`, activa el modo de edición y añade una Tarea llamada _"Entrega Práctica 1"_ y un **Foro de Dudas**.
  * Accede a `Configuración del curso > Copia de seguridad` y exporta el curso en un archivo comprimido **.mbz**. 
* Evidencias para Classroom:
  * Captura 1: Pantalla de `Administración del sitio > Cursos > Gestionar cursos y categorías` mostrando la estructura jerárquica creada.
  * Captura 2: El archivo de copia de seguridad del curso (con extensión .mbz) listo para entregar.
