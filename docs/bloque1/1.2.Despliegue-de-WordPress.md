# 1.2 Despliegue de WordPress Paso a Paso

Con el entorno local WAMP en ejecución (Apache y MySQL) y la base de datos creada, el siguiente paso práctico consiste en realizar el **despliegue del núcleo (Core) de WordPress** e interconectar el CMS con el servidor.

---

## 1. El Directorio Raíz Web (*DocumentRoot*)

El servidor web Apache busca y ejecuta los archivos de las aplicaciones dentro del directorio raíz público, denominado **DocumentRoot**.

* **Ruta local en XAMPP:** `C:\xampp\htdocs\`
* **Estructura del Proyecto:** Cada proyecto web debe organizarse en su propia subcarpeta dentro de `htdocs`. Para nuestras prácticas, la ruta de despliegue será:
  `C:\xampp\htdocs\mi_sitio_wordpress\`
* **Acceso desde el navegador:** `http://localhost/mi_sitio_wordpress`

---

## 2. Flujo del Asistente de Instalación Web

Al acceder por primera vez a la URL del proyecto, WordPress detecta que no existe el archivo de configuración base e inicia el **asistente de instalación web**:
| Campo del Asistente | Valor a Introducir | Justificación Técnica |
| :--- | :--- | :--- |
| **Nombre de la BD** | `bd_wordpress_altair` | Nombre asignado previamente en phpMyAdmin |
| **Usuario de la BD** | `root` | Administrador predeterminado de MySQL en XAMPP |
| **Contraseña** | *(en blanco)* | XAMPP local no asigna clave por defecto |
| **Servidor de la BD** | `localhost` | Indica que MySQL reside en el mismo equipo |
| **Prefijo de tabla** | `wp_` | Identificador inicial para las 12 tablas del core |
### 2.1 Justificación Técnica de los Datos de Conexión:
* **Usuario `root`:** Usuario administrador por defecto de MySQL en XAMPP.
* **Contraseña en blanco:** Por defecto, el entorno local de XAMPP no asigna contraseña al usuario `root`.
* **Servidor `localhost`:** Indica que el gestor MySQL reside en la misma máquina física que el servidor web Apache.
* **Prefijo de tabla (`wp_`):** Identificador que se antepone al nombre de cada una de las 12 tablas nativas creadas por WordPress (ej. `wp_posts`, `wp_users`, `wp_options`).

---

## 3. Generación del Archivo `wp-config.php`

Tras validar la conexión con la base de datos, el asistente escribe los parámetros introducidos en el archivo **`wp-config.php`**, ubicado en la raíz de la instalación.

```php
// Fragmento de configuración generado en wp-config.php
define( 'DB_NAME', 'bd_wordpress_altair' );
define( 'DB_USER', 'root' );
define( 'DB_PASSWORD', '' );
define( 'DB_HOST', 'localhost' );
define( 'DB_CHARSET', 'utf8mb4' );

$table_prefix = 'wp_';
::: tip Archivo wp-config-sample.php Si la instalación automatizada falla por falta de permisos de escritura en la carpeta htdocs, se puede renombrar el archivo wp-config-sample.php a wp-config.php e introducir manualmente las credenciales mediante un editor de código como VS Code. :::
