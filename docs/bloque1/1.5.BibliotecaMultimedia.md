# 1.5 Biblioteca Multimedia y Optimización de Medios

La **Biblioteca Multimedia** de WordPress es el repositorio centralizado donde se almacenan, gestionan y distribuyen todos los recursos digitales (*imágenes, documentos PDF, audios y vídeos*) utilizados en el sitio web. Una correcta gestión y optimización de los medios es crítica para el rendimiento (**WPO - Web Performance Optimization**), la accesibilidad y el posicionamiento en motores de búsqueda (SEO).

---

## 1. Funcionamiento de la Biblioteca de Medios (`Medios > Biblioteca`)

WordPress permite subir recursos directamente a la biblioteca para reutilizarlos en múltiples entradas, páginas o widgets.

### 1.1 Modos de Visualización:
* **Vista en Rejilla (*Grid View*):** Muestra miniaturas visuales de los archivos. Es ideal para la búsqueda rápida de imágenes.
* **Vista en Lista (*List View*):** Muestra una tabla detallada con el nombre del archivo, el autor que lo subió, la entrada/página a la que está adjunto, la fecha de subida y los comentarios.

### 1.2 Formatos de Archivo Admitidos por Defecto:
* **Imágenes:** `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.ico`.
* **Documentos:** `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.zip`.
* **Audio / Vídeo:** `.mp3`, `.m4a`, `.wav`, `.mp4`, `.mov`, `.avi`.

::: warning Archivos SVG en WordPress
Por razones de seguridad, WordPress **bloquea nativamente** la subida de archivos vectoriales `.svg` debido al riesgo de inyección de código XML malicioso. Para permitir el uso de SVG en el aula, se requiere un plugin específico (ej. *Safe SVG*) o la adición de funciones sanitizadas.
:::

## 2. Metadatos de Medios: Accesibilidad y SEO

Al seleccionar o subir cualquier recurso en la biblioteca multimedia, se despliega el panel de detalles del archivo. Rellenar correctamente estos campos es fundamental:
1. **Texto alternativo (Atributo `alt`):**
    * **Propósito:** Esencial para la **accesibilidad web**. Los lectores de pantalla para personas con discapacidad visual leen este texto. Además, si la imagen no se carga o la conexión falla, se muestra este texto descriptivo.
    * **Impacto SEO:** Los motores de búsqueda indexan el contenido de la imagen a través de su atributo `alt`.
2. **Título (*Title*):** Utilizado internamente por WordPress para organizar los medios en la base de datos.
3. **Leyenda (*Caption*):** Texto visible que aparece justo debajo de la imagen en la parte pública del sitio web (*Frontend*).
4. **Descripción:** Texto explicativo extenso almacenado en la página del adjunto (*Attachment Page*).

## 3. Optimización de Imágenes para la Web (WPO)

Uno de los errores más comunes en la administración web es subir imágenes tomadas directamente de cámaras o móviles con resoluciones excesivas (ej. 4000x3000px y +5 MB). Esto ralentiza drásticamente la carga de la página.

### 3.1 Reglas de Oro de Optimización:
* **Nombres de archivo limpios:** Renombrar siempre el archivo antes de subirlo. Usar minúsculas, sin acentos ni espacios, separados por guiones (ej. `servidor-apache-altair.jpg` en lugar de `IMG_2026_09.JPG`).
* **Dimensiones adecuadas:** Escalar la imagen a la dimensión máxima en que se mostrará en pantalla (habitualmente entre **800px y 1200px** de ancho para contenidos de entrada).
* **Compresión sin pérdida de calidad:** Reducir el peso del archivo a **menos de 150 KB - 200 KB** antes de la subida mediante herramientas web externas (Squoosh, TinyPNG) o software de edición.
* **Formato de nueva generación (WebP):** WebP ofrece una compresión un 30% mayor que JPEG manteniendo la misma calidad visual.

## 4. Generación Automática de Miniaturas y Ajustes de Medios

Al subir una imagen, WordPress realiza dos acciones automáticas:
1. Guarda el archivo original en la carpeta del servidor `C:\xampp\htdocs\mi_sitio\wp-content\uploads\AAAA\MM\`.
2. **Genera 3 recortes o miniaturas automáticos** para adaptar la imagen a diferentes dispositivos.

estos tamaños por defecto se configuran desde **Ajustes > Medios**:

* **Tamaño de la miniatura (*Thumbnail*):** `150 x 150 px` (Recorte exacto).
* **Tamaño medio (*Medium*):** `300 x 300 px` (Escala proporcional).
* **Tamaño grande (*Large*):** `1024 x 1024 px` (Escala proporcional).

## 5. Parámetros de Servidor para la Subida de Archivos

Cuando un usuario intenta subir un archivo pesado (como un instalador o un PDF extenso) y el servidor devuelve un error de carga, se debe a limitaciones impuestas en la configuración del entorno PHP.

### Parámetros clave en `php.ini` (XAMPP):
```ini
; Tamaño máximo permitido para archivos subidos individualmente
upload_max_filesize = 64M

; Tamaño máximo para el conjunto de datos enviados por formulario POST
post_max_size = 64M

; Límite máximo de memoria RAM asignada a la ejecución de scripts PHP
memory_limit = 256M
